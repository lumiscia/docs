---
title: 3D scenes
description: Build a 3D scene of shapes, text, models, lights and a camera, and composite it with 2D layers.
---

A 3D scene in a composition is a small graph of [scene nodes](../nodes/scene) that ends in a [`render_3d`](../nodes/scene/render-3d). The `render_3d` draws the scene into an ordinary raster with a transparent background, so you can merge it over a background, blur it or make it glow like any 2D layer. Use 3D for objects seen through a real camera, glTF models, extruded titles, and 2D layers placed in depth.

The examples name media files such as `fox.glb` and `studio.hdr`. Give your renderer whatever path, `media` alias or `asset:<id>` it resolves to the file.

## A first scene

Every port carries a `raster`, an image, or a `scene` of objects, lights and cameras. Scene nodes output scenes and take scenes, and `render_3d` takes one scene and outputs a raster. To draw several objects, a light and a camera together, wire them all into one [`merge_3d`](../nodes/scene/merge-3d), whose `objects` input takes any number of scenes, and wire the `merge_3d` into the `render_3d`.

This turns a gold torus in front of a camera and merges the render over a dark background:

```json title="torus.json"
{
  "timeline": { "fps": 30, "duration_frames": 120 },
  "render_settings": { "width": 1280, "height": 720 },
  "nodes": [
    { "id": 1, "type": "background", "params": { "paint": [18, 22, 32, 255] } },
    {
      "id": 2,
      "type": "shape_3d",
      "params": {
        "shape": "torus",
        "rotation": "=vec3(70, frame * 3, 0)",
        "color": "#e6b45a",
        "metallic": 1,
        "roughness": 0.25
      }
    },
    { "id": 3, "type": "camera_3d", "params": { "position": [0, 1.5, 4], "look_at": true } },
    { "id": 4, "type": "merge_3d" },
    { "id": 5, "type": "render_3d", "params": { "tone_mapping": "agx" } },
    { "id": 6, "type": "merge" },
    { "id": 7, "type": "media_output" }
  ],
  "connections": [
    { "from_node": 2, "to_node": 4, "to_port": "objects" },
    { "from_node": 3, "to_node": 4, "to_port": "objects" },
    { "from_node": 4, "to_node": 5, "to_port": "scene" },
    { "from_node": 1, "to_node": 6, "to_port": "base" },
    { "from_node": 5, "to_node": 6, "to_port": "overlay" },
    { "from_node": 6, "to_node": 7, "to_port": "source" }
  ]
}
```

Wiring a scene into a raster input, or a raster into a scene input, fails `check` with `connection.wrong_kind`. The scene has no light, so it gets a default key light and ambient fill.

## Units and transforms

World units are metres. X points right, Y points up, and a camera looks down its own -Z, so +Z points toward the viewer.

`position`, `rotation` and `scale` are `[x, y, z]` values, and an expression sets all three axes at once with `vec3(x, y, z)`. `rotation` is in degrees: yaw about Y first, then pitch about the turned X, then roll about the turned Z. A node scales first, then rotates, then moves.

A child's transform is in its parent's space. A `merge_3d` has its own `position`, `rotation` and `scale`, so a `merge_3d` inside another moves, turns or scales its whole group, which is how you build a hierarchy, such as a planet that carries its moon.

## The camera

[`camera_3d`](../nodes/scene/camera-3d) is the viewpoint. Set `look_at` to aim it at `target`, the origin by default, or aim it yourself with `rotation`. A perspective camera has a vertical `fov` of 40° by default, and an `orthographic` one keeps things the same size at any distance. The first camera wired into the scene is the one used. Without one, the scene is seen from `[0, 0, 5]`.

An expression on `position` moves the camera. This orbits the origin at a radius of 4:

```json
{
  "id": 3,
  "type": "camera_3d",
  "params": { "position": "=vec3(sin(time) * 4, 1.5, cos(time) * 4)", "look_at": true }
}
```

## Materials

[`shape_3d`](../nodes/scene/shape-3d), [`text_3d`](../nodes/scene/text-3d) and [`image_plane_3d`](../nodes/scene/image-plane-3d) share their material params. `color` is the base colour, `metallic` runs from plastic (0) to bare metal (1), and `roughness` from a mirror (0) to fully diffuse (1). `emissive` makes the surface give off light, and `unlit` shows the base colour as it is. `opacity` below 1 draws the object blended, after the opaque ones and back to front by their centres, so blended objects that cross each other can show in the wrong order.

A [`model_3d`](../nodes/scene/model-3d) uses the materials its glTF file defines.

## Lights

[`light_3d`](../nodes/scene/light-3d) is a `directional` light like the sun, a `point` light, a `spot` light or an `ambient` fill. `intensity` is a unitless multiplier, 3 by default, and point and spot lights fall off with the square of the distance.

`render_3d` also lights every surface from all around with an environment, a built-in studio by default, which gives metals something to reflect. Its `environment` param is that light's brightness, and 0 turns it off.

### Shadows

Turn on `cast_shadows` on a directional, spot or point light, and objects between it and others block its light. `shadow_softness` blurs the edges, in world units.

A shape with `shadow_catcher` shows nothing but the shadows that fall on it, darkening whatever the render is composited over. That stands a 3D object on a flat 2D background or on footage:

```json title="shadow-catcher.json"
{
  "timeline": { "fps": 30, "duration_frames": 90 },
  "render_settings": { "width": 1280, "height": 720 },
  "nodes": [
    { "id": 1, "type": "background", "params": { "paint": [70, 130, 160, 255] } },
    {
      "id": 2,
      "type": "shape_3d",
      "params": { "shape": "sphere", "position": [0, 0.5, 0], "color": "#f2f2f2" }
    },
    {
      "id": 3,
      "type": "shape_3d",
      "params": { "shape": "plane", "size": [10, 1, 10], "shadow_catcher": true }
    },
    {
      "id": 4,
      "type": "light_3d",
      "params": {
        "light": "directional",
        "intensity": 3,
        "rotation": [-55, -40, 0],
        "cast_shadows": true
      }
    },
    { "id": 5, "type": "light_3d", "params": { "light": "ambient", "intensity": 0.4 } },
    {
      "id": 6,
      "type": "camera_3d",
      "params": { "position": [0, 1.6, 4.2], "look_at": true, "target": [0, 0.4, 0] }
    },
    { "id": 7, "type": "merge_3d" },
    { "id": 8, "type": "render_3d" },
    { "id": 9, "type": "merge" },
    { "id": 10, "type": "media_output" }
  ],
  "connections": [
    { "from_node": 2, "to_node": 7, "to_port": "objects" },
    { "from_node": 3, "to_node": 7, "to_port": "objects" },
    { "from_node": 4, "to_node": 7, "to_port": "objects" },
    { "from_node": 5, "to_node": 7, "to_port": "objects" },
    { "from_node": 6, "to_node": 7, "to_port": "objects" },
    { "from_node": 7, "to_node": 8, "to_port": "scene" },
    { "from_node": 1, "to_node": 9, "to_port": "base" },
    { "from_node": 8, "to_node": 9, "to_port": "overlay" },
    { "from_node": 9, "to_node": 10, "to_port": "source" }
  ]
}
```

A `render_3d` draws shadows for the first 8 lights that cast them. Unlit and glowing surfaces cast shadows too, so turn `cast_shadows` off on a shape that stands in for a lamp.

## 2D layers in depth

[`image_plane_3d`](../nodes/scene/image-plane-3d) puts any raster on a flat rectangle facing +Z: text, an image, a video, or a whole 2D composition played by a `clip`. `width` is in world units and the height follows the raster's aspect ratio. A plane is unlit by default, so while it faces the camera it shows its raster's colours as they look in 2D.

Layers at different depths under a moving camera give parallax. This dollies past a title and a backdrop two units behind it:

```json title="parallax.json"
{
  "timeline": { "fps": 30, "duration_frames": 120 },
  "render_settings": { "width": 1280, "height": 720 },
  "nodes": [
    {
      "id": 1,
      "type": "background",
      "params": {
        "paint": {
          "type": "linear_gradient",
          "stops": [
            [0, "#1d4ed8"],
            [1, "#0f172a"]
          ],
          "start": [0, 0],
          "end": [0, 1]
        }
      }
    },
    {
      "id": 2,
      "type": "text",
      "params": {
        "content": "Depth",
        "font_size": 180,
        "position": [0, 250],
        "max_width": 1280,
        "alignment_horizontal": "center"
      }
    },
    {
      "id": 3,
      "type": "image_plane_3d",
      "params": { "width": 16, "position": [0, 0, -2], "opaque": true }
    },
    { "id": 4, "type": "image_plane_3d", "params": { "width": 4 } },
    {
      "id": 5,
      "type": "camera_3d",
      "params": {
        "position": "=vec3(tween(-1.5, 1.5, 0, 120, 'in_out_sine'), 0, 4.5)",
        "look_at": true
      }
    },
    { "id": 6, "type": "merge_3d" },
    { "id": 7, "type": "render_3d" },
    { "id": 8, "type": "media_output" }
  ],
  "connections": [
    { "from_node": 1, "to_node": 3, "to_port": "source" },
    { "from_node": 2, "to_node": 4, "to_port": "source" },
    { "from_node": 3, "to_node": 6, "to_port": "objects" },
    { "from_node": 4, "to_node": 6, "to_port": "objects" },
    { "from_node": 5, "to_node": 6, "to_port": "objects" },
    { "from_node": 6, "to_node": 7, "to_port": "scene" },
    { "from_node": 7, "to_node": 8, "to_port": "source" }
  ]
}
```

The backdrop has no transparent pixels, so `opaque` draws it with the opaque objects. Planes are blended by default and ordered by their centres, so keep blended planes apart in depth. `region` shows part of a raster on a plane, which cuts one picture into pieces at different depths without a `crop` per piece.

## Models

[`model_3d`](../nodes/scene/model-3d) draws a binary glTF (`.glb`) file with its materials, skins and morph targets, and plays one of its animation clips by name or index. glTF is in metres, but many models are built at another scale, so set `scale` to fit. A name the model doesn't have fails the render with a message that lists the names it does have.

```json title="fox.json"
{
  "timeline": { "fps": 30, "duration_frames": 120 },
  "render_settings": { "width": 1280, "height": 720 },
  "nodes": [
    {
      "id": 1,
      "type": "model_3d",
      "params": {
        "source": "fox.glb",
        "animation": "Run",
        "scale": [0.02, 0.02, 0.02],
        "rotation": [0, 90, 0]
      }
    },
    {
      "id": 2,
      "type": "camera_3d",
      "params": { "position": [0, 1.4, 4.2], "look_at": true, "target": [0, 0.7, 0] }
    },
    { "id": 3, "type": "merge_3d" },
    { "id": 4, "type": "render_3d" },
    { "id": 5, "type": "media_output" }
  ],
  "connections": [
    { "from_node": 1, "to_node": 3, "to_port": "objects" },
    { "from_node": 2, "to_node": 3, "to_port": "objects" },
    { "from_node": 3, "to_node": 4, "to_port": "scene" },
    { "from_node": 4, "to_node": 5, "to_port": "source" }
  ]
}
```

A raster wired into the model's `texture` input replaces the material that `texture_material` names, which puts a video on a screen. `lights` and `camera` bring in the model's own lights and cameras.

## Text and copies

[`text_3d`](../nodes/scene/text-3d) extrudes text into a solid, laid out as a `text` node with the same font would lay it out. `font_size` is in world units, 1 by default, and `bevel_size` rounds the edges.

[`instance_3d`](../nodes/scene/instance-3d) draws its input scene many times, up to 100,000, sharing its meshes on the GPU. Its `position`, `rotation` and `scale` are evaluated once per copy, with `instance` as the copy's index:

```json
{
  "id": 2,
  "type": "instance_3d",
  "params": {
    "count": 24,
    "position": "=vec3(sin(instance / instance_count * 6.2832) * 3, 0, cos(instance / instance_count * 6.2832) * 3)",
    "rotation": "=vec3(0, instance / instance_count * 360, 0)"
  }
}
```

## Environment maps

`environment_map` on `render_3d` lights the scene with an equirectangular `.hdr` or `.exr` file instead of the studio, for its reflections and light. `environment_background` shows the map behind the scene, and `environment_background_blur` softens it.

```json title="environment.json"
{
  "timeline": { "fps": 30, "duration_frames": 90 },
  "render_settings": { "width": 1280, "height": 720 },
  "nodes": [
    {
      "id": 1,
      "type": "shape_3d",
      "params": { "shape": "sphere", "color": "#ffffff", "metallic": 1, "roughness": 0.05 }
    },
    { "id": 2, "type": "camera_3d", "params": { "position": [0, 0.4, 3], "look_at": true } },
    { "id": 3, "type": "merge_3d" },
    {
      "id": 4,
      "type": "render_3d",
      "params": {
        "environment_map": "studio.hdr",
        "environment_rotation": "=time * 20",
        "environment_background": true,
        "environment_background_blur": 0.3
      }
    },
    { "id": 5, "type": "media_output" }
  ],
  "connections": [
    { "from_node": 1, "to_node": 3, "to_port": "objects" },
    { "from_node": 2, "to_node": 3, "to_port": "objects" },
    { "from_node": 3, "to_node": 4, "to_port": "scene" },
    { "from_node": 4, "to_node": 5, "to_port": "source" }
  ]
}
```

A map is decoded and prefiltered the first time a render uses it, which adds a fraction of a second to that frame. Turning it or changing its brightness reads nothing again.

## Depth and normals

`render_3d`'s `output` can be `depth` or `normal` instead of the lit scene, for 2D effects such as fog, depth of field or relighting. Draw the same scene with a second `render_3d` for each. The [`render_3d` page](../nodes/scene/render-3d#example) fades distant objects into the background through a depth mask.

## Performance

A `render_3d` is drawn again only on frames where something in its scene changes. A still scene, or a posed model with no clip over planes of still images, is drawn once. A video on a plane, or a model playing a looping clip, redraws it on every frame.

`supersample`, 2 by default, renders the scene at that multiple of the width and height, then averages down to antialias edges. 1 is a quarter of the pixels of the default. Use `instance_3d` rather than many copies of a node, and `region` rather than a `crop` per image plane.

## Limits

| Limit                                                        | Value                                                     |
| ------------------------------------------------------------ | --------------------------------------------------------- |
| Objects in one frame's scene, counting every copy            | 100,000                                                   |
| `instance_3d` `count`                                        | 0 to 100,000, nested up to 8 deep                         |
| Lights casting shadows in one `render_3d`                    | 8; the rest light without shadows                         |
| `supersample`                                                | 1 to 4, lowered if the target won't fit the GPU            |
| A model                                                      | 4,000,000 vertices, 12,000,000 indices, 1024 joints a skin, 256 morph targets a mesh, textures 8192 pixels a side |
| `text_3d`                                                    | The renderer's text glyph limit (16384 by default), 4,000,000 vertices, 12,000,000 indices |
| An environment map                                           | 256 MiB, 8192 pixels a side, 8192 × 4096 in all           |

A model or map past a limit fails with `media.too_large`, and a scene or text past one fails the render.
