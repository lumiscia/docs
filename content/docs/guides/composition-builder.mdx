title: Composition builder

`Composition` from `@lumiscia/lumen-shared` builds composition JSON in TypeScript. Node types and params are typed from the generated schema, so a wrong param name or enum value is a type error.

```bash
npm install @lumiscia/lumen-shared
```

`@lumiscia/lumen-sdk` re-exports everything in `@lumiscia/lumen-shared`, so if you use the SDK, import `Composition`, the expression helpers, `defineComposition`, `prop`, `fn` and `wgslShader` from `@lumiscia/lumen-sdk` instead.

## Create a composition

```ts
import { Composition } from "@lumiscia/lumen-shared";

const composition = new Composition({
  metadata: { name: "Launch card" },
  renderSettings: { width: 1280, height: 720 },
  timeline: { fps: 30, durationSeconds: 4 },
});
```

`timeline` takes `duration_frames` or `durationSeconds`, which rounds up to whole frames. Without options, a composition is 1920×1080 at 30 fps and 1 frame long, so always set a duration. Pass every setting to the constructor, since a composition has no setters. To fill the frame with a color, add a `background` node.

## Add and connect nodes

`addNode()` takes the node's `type` and `params`, with the same snake_case names as the JSON, plus optional `inputs`, and returns the node. Ids count up from 0 unless you pass an `id`.

```ts
const background = composition.addNode({
  type: "background",
  params: { paint: [18, 24, 32, 255] },
});

const title = composition.addNode({
  type: "text",
  params: {
    content: "Lumiscia",
    font_size: 96,
    position: [120, 300],
  },
});

const stack = composition.addNode({
  type: "raster_multimerge",
  inputs: { layers: [background, title] },
});
composition.addNode({ type: "media_output", inputs: { source: stack } });
```

`inputs` maps each input port to the node that feeds it, and a variadic port such as `layers` takes an array. Port names are typed from the node type. `raster_multimerge` stacks its `layers` in connection order, so the title draws over the background.

`connect(from, to, { toPort })` adds the same connection after both nodes exist. It takes nodes or ids, and `toPort` is required. The connection always leaves the `output` port. `inputs` and `connect` throw for a node from another composition. See [Connections](../composition-format#connections) for each node's port names.

## Animate params

A param that takes an expression string such as `"=progress(0, 30)"` also takes an `Expr` from the expression helpers, type-checked against the param. This version of the title fades in over 1 second and rises 40 pixels:

```ts
import { ease, progress, sec, tween } from "@lumiscia/lumen-shared";

const title = composition.addNode({
  type: "text",
  params: {
    content: "Lumiscia",
    font_size: 96,
    opacity: progress(0, sec(1)),
    position: tween([120, 340], [120, 300], 0, sec(0.6), ease.outCubic),
  },
});
```

`toJSON()` writes these as `"=progress(0, 1s)"` and `"=tween(vec2(120, 340), vec2(120, 300), 0, 0.6s, 'out_cubic')"`.

`fn()` defines a reusable expression function, and `addFunction()` adds it to the composition's `functions`:

```ts
import { fn, tween, type Num } from "@lumiscia/lumen-shared";

const rise = fn("rise(start)", (start: Num) => tween(0, 1, start, 12, "out_cubic"));
composition.addFunction(rise);
```

`rise(10)` is then an `Expr<number>` for any number param, written as `"=rise(10)"`.

For a form the helpers don't cover, such as `if(..)` or `node(..)`, wrap the expression text, without its `=`, in `expr()`: `expr("if(frame > 30, 1, 0)")`. To pass text that starts with `=` as literal text, wrap it in `literal()`, which escapes the `=` as `==`.

Params nested in rich text, such as the fields of a text node's spans and decorations, also take an `Expr`. Type such a value built outside `addNode` with `ExpressionInput`, as in `ExpressionInput<TextSpan>`. See [Expressions](../expressions) for the syntax and every built-in, and [Animation](animation) for common patterns.

## Reuse a template

`defineComposition()` builds a template that `clip` nodes play. `build` adds the template's nodes and returns the node it outputs, and the builder adds the template's `media_output`. Props declared with `prop.string()`, `prop.number()`, `prop.color()` or `prop.vec2()` arrive in `build` as typed expressions.

```ts
import { defineComposition, prop } from "@lumiscia/lumen-shared";

const lowerThird = defineComposition({
  name: "lower_third",
  size: { width: 800, height: 160 },
  duration: 90,
  props: { name: prop.string("Untitled"), accent: prop.color([255, 196, 0, 255]) },
  build: (c, { name, accent }) =>
    c.addNode({
      type: "text",
      params: { content: name, color: accent, font_size: 56 },
    }),
});

const card = composition.addNode(lowerThird.clip({ start: 15, props: { name: "Ada Lovelace" } }));
const placed = composition.addNode({
  type: "transform",
  params: { translate_x: 80, translate_y: 520 },
  inputs: { source: card },
});

composition.connect(placed, stack, { toPort: "layers" });
```

Adding a clip registers its template in `compositions`, and `connect` adds `placed` to the existing `stack` as its top layer. A clip draws at the template's size from the top-left corner of the canvas, so the `transform` moves it into place. `clip()` also takes `duration`, `offset`, `speed` and `end`; see [Templates](../composition-format#templates).

## Add audio

`addAudio()` adds a clip, with every time in seconds: `start` on the timeline, `duration`, and `offset` into the source.

```ts
composition
  .addAudioTrack({ id: "music", gain: 0.8 })
  .addAudio({ source: "song", start: 0, duration: 4, offset: 1.5, trackId: "music" });
```

`source` is the manifest alias of an uploaded audio file. `trackId` defaults to `main`, a track that isn't declared yet becomes a plain track, and clips may overlap. To set a track's `name`, `muted`, `solo` or `gain`, call `addAudioTrack()` before the track's first clip. Clips take a `gain` too. Times are written to the JSON as whole milliseconds.

## Serialize and render

`toJSON()` returns the composition as plain JSON. Use it to store a composition, send it from a browser editor to your backend, or pass it to a preview. `render()` from `@lumiscia/lumen-sdk` accepts the `Composition` itself.

```ts
import { Lumen } from "@lumiscia/lumen-sdk";

const lumen = new Lumen({
  apiKey: process.env.LUMISCIA_API_KEY!,
  baseUrl: "https://api.lumiscia.com/v1",
});

const { id } = await lumen.render(composition);
```

A composition that uses media, like the `song` alias above, also needs a `media` manifest. See [Media sources](media-sources).
