---
title: Preview to render
description: Preview a composition in the browser, then render the same composition through your backend.
---

The browser preview and Lumiscia's GPU workers run the same Lumen engine on the same composition JSON. You build and preview a composition in the browser, then send it unchanged to your backend for the final render. Media is the main difference. The preview takes files directly, and a render takes a manifest of uploaded media under the same aliases.

<Steps>
<Step>
### Preview with local files

Register each file under the alias its `media_in` node uses. The preview plays the composition with no uploads and no API key.

```tsx title="Editor.tsx"
import { LumenCanvas, createLumenPreview } from "@lumiscia/lumen-react";
import type { MediaRegistration } from "@lumiscia/lumen-react";
import { createLumenBindings } from "@lumiscia/lumen-bindings/bundler";

const preview = createLumenPreview();
const bindings = createLumenBindings();

export function Editor({ compositionJson, file }: { compositionJson: string; file: File }) {
  const mediaSources: MediaRegistration[] = [{ kind: "image", id: "hero", source: file }];

  return (
    <LumenCanvas
      preview={preview}
      bindings={bindings}
      compositionJson={compositionJson}
      mediaSources={mediaSources}
    />
  );
}
```

[React](../sdks/react) and [Svelte](../sdks/svelte) cover setup, playback controls and audio.

</Step>
<Step>
### Upload the files

Upload each file to Lumiscia while the user edits, and keep the returned media id next to its alias. Uploads need your API key, so run them on your backend. See [Media sources](media-sources) for upload and URL ingest.

</Step>
<Step>
### Render from your backend

Send the composition JSON and the manifest to your backend, and render there with `@lumiscia/lumen-sdk`.

```ts title="render.ts"
import { Lumen, mediaReference, type LumenComposition } from "@lumiscia/lumen-sdk";

const lumen = new Lumen({
  apiKey: process.env.LUMISCIA_API_KEY!,
  baseUrl: "https://api.lumiscia.com/v1",
});

export async function renderEdit(composition: LumenComposition, heroMediaId: string) {
  return lumen.render(composition, {
    media: { hero: mediaReference(heroMediaId) },
    webhookUrl: "https://example.com/webhooks/lumiscia",
  });
}
```

In a Cloudflare Worker, import from `@lumiscia/lumen-sdk/cloudflare` instead.

</Step>
<Step>
### Wait for the result

`render()` returns the render's `id`. Wait with `waitForRender(id)`, poll `getRender(id)`, or receive a [webhook](webhooks) when it finishes. Then download the artifact with `getRenderArtifact(id)`. See the [Node SDK](../sdks/node).

</Step>
</Steps>

## What to check before rendering

- Every alias registered in the preview has an entry in the render's `media` manifest.
- Every manifest entry points at media whose `status` is `validated`, and that hasn't expired.
- The composition has the size, frame rate and duration you want, within your plan's limits.
- Text uses fonts the render has. Lumen bundles one font, Roboto, and a font you load into the browser preview isn't part of the render request, so text in another family can look different in the render.
