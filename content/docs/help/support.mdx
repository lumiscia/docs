---

For support, email [support@lumiscia.com](mailto:support@lumiscia.com) or use the [contact page](https://lumiscia.com/contact).

Users on Pro plans receive priority support. We still review reports from all users, but response times can vary during beta.

## What To Include

When asking for help, include the details that are relevant to the issue:

- workspace or account context,
- render id,
- input hash if available,
- SDK package and version,
- composition JSON or a reduced reproduction,
- media type, codec, dimensions, and duration when media is involved,
- browser, runtime, or deployment platform if the issue is SDK-related.

## Render Issues

For failed or slow renders, include the render id and whether the job was `queued`, `processing`, `succeeded`, or `failed`.

If the problem involves media, include whether the file was uploaded directly or ingested from a URL.

## Billing Questions

For billing or usage questions, include the workspace, approximate time range, and any render ids or input hashes connected to the charge.
