Report security issues privately as described in the lumen-oss [security policy](https://github.com/lumiscia/lumen-oss/blob/main/SECURITY.md), not in public GitHub issues.

## What to include

Send the details that apply to your issue:

- workspace,
- render id and input hash,
- SDK package and version,
- composition JSON, or a reduced composition that reproduces the problem,
- media type, codec, dimensions, and duration, when media is involved,
- browser, runtime, or deployment platform, for SDK and preview issues.

## Render issues

For failed or slow renders, include the render id and its last status (`queued`, `processing`, `succeeded`, or `failed`). If media is involved, say whether you uploaded the file or registered it from a URL.

## Billing questions

Include the workspace, the approximate time range, and the render ids or input hashes behind the charge. Every charge also appears in the usage history in the dashboard.
