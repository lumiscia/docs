title: Quick start
description: Render your first video with the Lumiscia API and the TypeScript SDK.

Lumiscia renders video from JSON compositions on hosted GPUs. You send a composition to the API, a GPU worker renders it with Lumen, and you download the MP4 artifact.

<Callout type="info" title="Lumiscia is in beta">
  Pricing, concurrency, queue times, and SDK APIs can change during beta. Read the [beta
  notes](beta-notes) before you run production workloads.
</Callout>

<Steps>
<Step>

### Get an API key

Sign up at [lumiscia.com](https://lumiscia.com) and create a key on the API keys page of the dashboard. The Free plan adds $5 of credit each month, enough for 500 renders at the 5-second minimum.

```bash
export LUMISCIA_API_KEY="your-api-key"
```

</Step>
<Step>

### Install the SDK

```bash
npm install @lumiscia/lumen-sdk
```

The examples on this page run on Node.js. For Cloudflare Workers, import from `@lumiscia/lumen-sdk/cloudflare` instead (see the [Cloudflare SDK](sdks/cloudflare)).

</Step>
<Step>

### Write a composition

A composition sets the timeline, the output size, and a graph of nodes. This one fills a 1280×720 frame with a dark background for 3 seconds (90 frames at 30 fps).

```ts title="render.mts"
import { writeFile } from "node:fs/promises";
import { Lumen, type LumenComposition } from "@lumiscia/lumen-sdk";

const composition: LumenComposition = {
  timeline: { fps: 30, duration_frames: 90 },
  render_settings: { width: 1280, height: 720 },
  nodes: [
    { id: 1, type: "background", params: { paint: [18, 24, 32, 255] } },
    { id: 2, type: "media_output" },
  ],
  connections: [{ from_node: 1, from_port: "output", to_node: 2, to_port: "source" }],
};
```

The `background` node outputs a frame filled with `paint`. Its `width` and `height` default to 0, which matches the composition size. The connection feeds that frame into `media_output`, the node every composition ends at.

</Step>
<Step>

### Submit the render

Add this to `render.mts`:

```ts title="render.mts"
const lumen = new Lumen({
  apiKey: process.env.LUMISCIA_API_KEY!,
  baseUrl: "https://api.lumiscia.com/v1",
});

const { id, error } = await lumen.render(composition);

if (error || !id) {
  throw new Error(error?.message ?? "Render was not created");
}

console.log("Render queued:", id);
```

`render()` returns API errors in `error` instead of throwing. A validation error names the field or node that failed. Always set `baseUrl`, because the SDK's default points at the dashboard proxy.

</Step>
<Step>

### Download the artifact

Wait for the render to finish, then save the MP4:

```ts title="render.mts"
await lumen.waitForRender(id);

const artifact = await lumen.getRenderArtifact(id);
await writeFile("render.mp4", Buffer.from(await artifact.arrayBuffer()));
```

`waitForRender()` listens on the render's event socket and rejects if the render fails. Run the script with Node.js 22.18 or later, which runs TypeScript files directly:

```bash
node render.mts
```

</Step>
</Steps>

## Add media

To use an image or video, upload it, give it an alias in the render's `media` manifest, and reference the alias from a `media_in` node.

```ts
import { readFile } from "node:fs/promises";
import { mediaReference } from "@lumiscia/lumen-sdk";

const bytes = await readFile("hero.png");
const hero = await lumen.uploadMedia({
  body: bytes,
  contentType: "image/png",
  fileName: "hero.png",
  sizeBytes: bytes.byteLength,
});

const { id, error } = await lumen.render(composition, {
  media: { hero: mediaReference(hero) },
});
```

`mediaReference()` turns the upload into a `lumen:<media_id>` reference. In the composition, add a `media_in` node whose `source` is the alias, never the media id, and connect its `output` port like any other source:

```json
{ "id": 3, "type": "media_in", "params": { "kind": "image", "source": "hero" } }
```

Uploads expire after 24 hours, so upload media shortly before you render it. See [Media sources](guides/media-sources) for video, URL ingest, and large files.
