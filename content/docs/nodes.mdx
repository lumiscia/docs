title: Nodes

---

Nodes are the building blocks of a composition. Lumen, the open-source engine, defines them. Each node has a type string, input and output ports, and optional properties.

## Categories

- [Compositing](nodes/compositing): combine raster layers, apply masks, and choose between inputs.
- [Processing](nodes/processing): adjust, transform, retime, crop, blur, and shade raster frames.
- [Source](nodes/source): create raster frames from media, colors, and text.
- [Vector](nodes/vector): create GPU-rendered shape and path graphics.
- [Output](nodes/output): define the final render result.

## Common Rules

- A composition must contain exactly one `media_output`.
- Required input ports must be connected.
- Raster outputs connect to raster inputs.
- Shape, path, and text nodes now produce raster frames directly.
- Properties can be literal values or expressions where the property type supports animation.
