---
title: Boolean
description: Combines two raster alpha masks with boolean operations.
---

`boolean` combines the alpha of inputs `a` and `b` into one mask. Use it to cut shapes out of each other, then feed the result to the `mask` input of `merge`.

<NodeReference type="boolean" />

## Example

```json
{
  "id": 1,
  "type": "boolean",
  "params": {
    "operation": "subtract"
  }
}
```
