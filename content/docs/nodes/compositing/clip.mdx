`clip` plays a template from the composition's top-level `compositions` map, or its `source` input, during a window of frames. Use it to reuse one template several times with different `props`, or to place a branch of the graph on the timeline.

<NodeReference type="clip" />

## Example

This plays the `lower_third` template from `compositions` for 90 frames, starting at frame 30, and sets its `title` prop.

```json
{
  "id": 1,
  "type": "clip",
  "params": {
    "composition": "lower_third",
    "start": 30,
    "duration": 90,
    "props": {
      "title": "Ada Lovelace"
    }
  }
}
```
