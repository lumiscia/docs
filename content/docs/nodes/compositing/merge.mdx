import { NodeReference } from "@/src/components/mdx/node-reference";

`merge` draws an `overlay` raster over a `base` raster, optionally through a `mask`. Use it for one foreground layer, and `raster_multimerge` for longer stacks.

<NodeReference type="merge" />

## Example

```json
{
  "id": 1,
  "type": "merge",
  "params": {
    "blend_mode": "screen",
    "opacity": 0.8
  }
}
```
