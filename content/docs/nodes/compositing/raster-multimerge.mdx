---
title: Raster Multi Merge
description: Composites a variadic stack of raster layers in order.
---

`raster_multimerge` composites every raster connected to `layers` in connection order, with the first at the bottom. Use it for layer stacks instead of chaining `merge` nodes.

<NodeReference type="raster_multimerge" />

## Example

```json
{
  "id": 1,
  "type": "raster_multimerge",
  "params": {
    "blend_mode": "multiply",
    "opacity": 0.9
  }
}
```
