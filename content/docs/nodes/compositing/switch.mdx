---
title: Switch
description: Selects one raster input according to a controlled layer index.
---

import { NodeReference } from "@/src/components/mdx/node-reference";

`switch` routes one of the rasters connected to `layers` to its output, picked by the zero-based `selected_layer`. Use it with an expression to cut between branches of the graph.

<NodeReference type="switch" />

## Example

```json
{
  "id": 1,
  "type": "switch",
  "params": {
    "selected_layer": "=if(frame < 30, 0, 1)"
  }
}
```
