---
title: Media Output
description: Copies the compiled raster into the final composition output.
---

`media_output` marks the raster that becomes the rendered video. A composition has exactly one, with the last node of the graph connected to its `source` input.

<NodeReference type="media_output" />

## Example

Connect the last node's `output` to the `source` input of `media_output`:

```json
{
  "nodes": [
    { "id": 1, "type": "background", "params": { "paint": [16, 24, 32, 255] } },
    { "id": 2, "type": "media_output" }
  ],
  "connections": [{ "from_node": 1, "from_port": "output", "to_node": 2, "to_port": "source" }]
}
```
