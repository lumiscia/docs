title: Media Output

`media_output` marks the raster that becomes the rendered video. A composition has exactly one, with the last node of the graph connected to its `source` input.

Lumen composites in linear light with 16-bit float precision. `media_output` encodes the result to sRGB and quantises it once, to the output's format. An opaque output, such as an MP4 or a JPEG, composites the frame over black first. 8-bit output is dithered, so smooth gradients don't band, while 8-bit images and colors written in the composition keep their exact codes.

## Example

Connect the last node to the `source` input of `media_output`:

```json
{
  "nodes": [
    { "id": 1, "type": "background", "params": { "paint": [16, 24, 32, 255] } },
    { "id": 2, "type": "media_output" }
  ],
  "connections": [{ "from_node": 1, "to_node": 2, "to_port": "source" }]
}
```
