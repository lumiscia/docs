---
title: Blur
description: Applies a separable Gaussian blur to a raster.
---

`blur` softens a raster with a Gaussian blur. Animate `radius` with an expression to pull focus in or out.

<NodeReference type="blur" />

## Example

```json
{
  "id": 1,
  "type": "blur",
  "params": {
    "radius": "=tween(0, 12, 0, 30, 'out_cubic')"
  }
}
```
