---
title: channel_shuffle
description: Remap output channels from source channels or constants.
---

## Properties

| Property | Type   | Default   |
| -------- | ------ | --------- |
| `red`    | string | `"red"`   |
| `green`  | string | `"green"` |
| `blue`   | string | `"blue"`  |
| `alpha`  | string | `"alpha"` |

Selectors include `red`, `green`, `blue`, `alpha`, `zero`, `one`, or numeric constants.

Example: set `alpha` to `one` to force an opaque result.
