---
title: Channel Shuffle
description: Remaps source raster color channels.
---

import { NodeReference } from "@/src/components/mdx/node-reference";

`channel_shuffle` fills each output channel from any source channel or from a constant. Set `alpha` to `one` to make a raster fully opaque, or set `red`, `green` and `blue` to `alpha` to view its matte.

<NodeReference type="channel_shuffle" />

## Example

```json
{
  "id": 1,
  "type": "channel_shuffle",
  "params": {
    "alpha": "one"
  }
}
```
