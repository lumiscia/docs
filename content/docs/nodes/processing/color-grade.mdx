---
title: Color Grade
description: Applies a LUT-driven color transform to a raster.
---

`color_grade` maps colors through a lookup table and blends the result in by `strength`. Set `lut_source` to `rgb1d:` followed by at least two `r,g,b` triplets separated by `;`, in 0 to 255 or 0 to 1, or to `identity` for no change. `interpolation` is `0` for nearest sampling and `1` for linear.

<NodeReference type="color_grade" />

## Example

```json
{
  "id": 1,
  "type": "color_grade",
  "params": {
    "lut_source": "rgb1d: 0,0,0; 255,128,0; 255,255,255",
    "strength": 0.6
  }
}
```
