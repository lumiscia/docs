import { NodeReference } from "@/src/components/mdx/node-reference";

`crop` keeps a rectangle of the source in place and clears everything outside it to transparent. Use `resize` instead when you want to scale a region to new bounds.

<NodeReference type="crop" />

## Example

```json
{
  "id": 1,
  "type": "crop",
  "params": {
    "x": 160,
    "y": 90,
    "width": 960,
    "height": 540
  }
}
```
