`crop` keeps a rectangle of the source in place and clears everything outside it to transparent. To scale the cropped region to new bounds, follow it with `resize`. Per-pixel nodes in between, such as `exposure`, `levels` or `opacity`, keep the crop's bounds, so `resize` still scales only the cropped region.

<NodeReference type="crop" />

## Example

```json
{
  "id": 1,
  "type": "crop",
  "params": {
    "x": 160,
    "y": 90,
    "width": 960,
    "height": 540
  }
}
```
