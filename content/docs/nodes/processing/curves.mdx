---
title: Curves
description: Applies a 1D RGB curve table to a raster.
---

import { NodeReference } from "@/src/components/mdx/node-reference";

`curves` remaps red, green and blue through a curve table. `curve_source` uses the same `rgb1d:` triplet format as `color_grade`, and `identity` leaves colors unchanged.

<NodeReference type="curves" />

## Example

```json
{
  "id": 1,
  "type": "curves",
  "params": {
    "curve_source": "rgb1d: 0,0,0; 128,96,80; 255,255,255"
  }
}
```
