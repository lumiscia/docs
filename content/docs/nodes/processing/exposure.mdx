---
title: Exposure
description: Adjusts raster exposure, contrast, and offset.
---

`exposure` shifts brightness in stops, scales contrast and adds a color offset. Alpha passes through unchanged.

<NodeReference type="exposure" />

## Example

```json
{
  "id": 1,
  "type": "exposure",
  "params": {
    "exposure": 0.5,
    "contrast": 1.1
  }
}
```
