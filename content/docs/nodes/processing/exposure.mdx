---
title: exposure
description: Adjust exposure, contrast, and RGB offset.
---

## Properties

| Property   | Type  | Default | Notes                             |
| ---------- | ----- | ------- | --------------------------------- |
| `exposure` | float | `0`     | Exposure in stops.                |
| `contrast` | float | `1`     | Contrast around midpoint `0.5`.   |
| `offset`   | float | `0`     | Added before contrast is applied. |

Alpha is preserved.
