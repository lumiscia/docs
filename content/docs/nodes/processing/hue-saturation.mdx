---
title: Hue Saturation
description: Adjusts raster hue, saturation, and lightness.
---

`hue_saturation` rotates hue, scales saturation and offsets lightness. Set `saturation` to `0` for grayscale.

<NodeReference type="hue_saturation" />

## Example

```json
{
  "id": 1,
  "type": "hue_saturation",
  "params": {
    "saturation": 0
  }
}
```
