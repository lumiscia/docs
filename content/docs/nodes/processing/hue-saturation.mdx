---
title: hue_saturation
description: Adjust hue, saturation, and lightness.
---

## Properties

| Property      | Type  | Default | Notes                  |
| ------------- | ----- | ------- | ---------------------- |
| `hue_degrees` | float | `0`     | Hue offset in degrees. |
| `saturation`  | float | `1`     | Multiplies saturation. |
| `lightness`   | float | `0`     | Adds to HSL lightness. |

Use `saturation: 0` for grayscale.
