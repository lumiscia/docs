---
title: Levels
description: Remaps raster black, white, gamma, and output range.
---

`levels` maps the input range between `black_point` and `white_point` to the range between `output_black` and `output_white`, with `gamma` for the midtones. Use it to fix washed-out or crushed footage.

<NodeReference type="levels" />

## Example

```json
{
  "id": 1,
  "type": "levels",
  "params": {
    "black_point": 0.05,
    "white_point": 0.95,
    "gamma": 1.1
  }
}
```
