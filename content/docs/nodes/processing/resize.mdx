---
title: Resize
description: Resamples a raster into a rectangle placed on the composition canvas.
---

`resize` scales the source into a `width` by `height` rectangle placed at `x`, `y` on the canvas. `mode` picks whether the source stretches to the rectangle, fits inside it or fills it.

<NodeReference type="resize" />

## Example

```json
{
  "id": 1,
  "type": "resize",
  "params": {
    "width": 640,
    "height": 360,
    "mode": "fit"
  }
}
```
