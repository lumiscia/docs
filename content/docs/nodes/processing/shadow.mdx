title: Shadow

import { NodeReference } from "@/src/components/mdx/node-reference";

`shadow` draws a blurred, offset copy of the source's alpha behind the source. Use it for drop shadows under text and shapes.

<NodeReference type="shadow" />

## Example

```json
{
  "id": 1,
  "type": "shadow",
  "params": {
    "offset_x": 0,
    "offset_y": 12,
    "radius": 16,
    "opacity": 0.4
  }
}
```
