`time_remap` renders its source at the frame given by `frame` instead of the current one. Use expressions for slow motion, holds and reverse playback.

A `frame` below 0 renders frame 0, and one that isn't finite is an error. With `loop_enabled`, frames wrap from `loop_end` back to `loop_start`, and `loop_end` itself is never shown.

<NodeReference type="time_remap" />

## Example

This plays the source at half speed.

```json
{
  "id": 1,
  "type": "time_remap",
  "params": {
    "frame": "=frame / 2"
  }
}
```
