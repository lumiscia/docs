---
title: Transform
description: Transforms a raster into the composition canvas bounds.
---

`transform` moves, scales and rotates a raster within the composition canvas. Its params are usually animated with expressions.

<NodeReference type="transform" />

## Example

```json
{
  "id": 1,
  "type": "transform",
  "params": {
    "translate_x": "=tween(-200, 0, 0, 20, 'out_cubic')",
    "rotate": "=sin(time * 2) * 5"
  }
}
```
