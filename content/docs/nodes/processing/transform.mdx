`transform` moves, scales and rotates a raster within the composition canvas. Its params are usually animated with expressions.

Scale and rotation pivot on the source's center. To pivot elsewhere, set `custom_pivot` to `true` along with `pivot_x` and `pivot_y`. A pivot set without `custom_pivot: true` is an error.

<NodeReference type="transform" />

## Example

```json
{
  "id": 1,
  "type": "transform",
  "params": {
    "translate_x": "=tween(-200, 0, 0, 20, 'out_cubic')",
    "rotate": "=sin(time * 2) * 5"
  }
}
```
