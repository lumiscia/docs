---
title: transform
description: Translate, scale, and rotate a raster.
---

## Properties

| Property      | Type  | Default |
| ------------- | ----- | ------- |
| `translate_x` | float | `0`     |
| `translate_y` | float | `0`     |
| `scale_x`     | float | `1`     |
| `scale_y`     | float | `1`     |
| `rotate`      | float | `0`     |
| `pivot_x`     | float | `0`     |
| `pivot_y`     | float | `0`     |
| `sampling`    | int   | `1`     |

Transform properties are commonly animated with expressions.
