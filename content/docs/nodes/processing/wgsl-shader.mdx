`wgsl_shader` runs your own WGSL compute shader over the rasters connected to `source`. Use it for effects the built-in nodes don't cover.

<NodeReference type="wgsl_shader" />

## Example

The engine appends a prelude that binds the first input as `input0`, the output texture as `output`, and frame globals as `lumen`. Declare your own uniform struct at `@group(0) @binding(1)`. The entry point is `cs_main`, and inputs and output are premultiplied alpha.

This shader inverts colors by `amount`:

```wgsl
struct Params { amount: f32 };
@group(0) @binding(1) var<uniform> params: Params;

@compute @workgroup_size(8, 8, 1)
fn cs_main(@builtin(global_invocation_id) id: vec3<u32>) {
  let size = textureDimensions(output);
  if (id.x >= size.x || id.y >= size.y) {
    return;
  }
  let color = textureLoad(input0, vec2<i32>(id.xy), 0);
  let inverted = vec3<f32>(color.a) - color.rgb;
  textureStore(output, vec2<i32>(id.xy), vec4<f32>(mix(color.rgb, inverted, params.amount), color.a));
}
```

Set `shader` to that source and `uniforms` to `{ "amount": "=progress(0, 30)" }` to fade the effect in over the first 30 frames.
