---
title: Merge 3D
description: Groups scenes into one, placed together by its transform.
---

import { NodeReference } from "@/src/components/mdx/node-reference";

`merge_3d` groups the scenes wired into `objects` into one scene. [`render_3d`](render-3d) draws one scene, so wire the objects, lights and camera you want drawn together into a `merge_3d` and the `merge_3d` into the `render_3d`.

Its `position`, `rotation` and `scale` place everything inside it together. A child's transform is in its parent's space, so merges nested in merges build a hierarchy: a group that turns carries its objects with it. Scale applies first, then rotation, then position.

<NodeReference type="merge_3d" />

## Example

Two shapes that turn together about Y, seen by a camera outside the group:

```json
{
  "nodes": [
    { "id": 1, "type": "shape_3d", "params": { "position": [1.2, 0, 0], "size": [0.8, 0.8, 0.8] } },
    {
      "id": 2,
      "type": "shape_3d",
      "params": { "shape": "sphere", "position": [-1.2, 0, 0], "size": [0.8, 0.8, 0.8] }
    },
    { "id": 3, "type": "merge_3d", "params": { "rotation": "=vec3(0, time * 45, 0)" } },
    { "id": 4, "type": "camera_3d", "params": { "position": [0, 2, 5], "look_at": true } },
    { "id": 5, "type": "merge_3d" },
    { "id": 6, "type": "render_3d" },
    { "id": 7, "type": "media_output" }
  ],
  "connections": [
    { "from_node": 1, "to_node": 3, "to_port": "objects" },
    { "from_node": 2, "to_node": 3, "to_port": "objects" },
    { "from_node": 3, "to_node": 5, "to_port": "objects" },
    { "from_node": 4, "to_node": 5, "to_port": "objects" },
    { "from_node": 5, "to_node": 6, "to_port": "scene" },
    { "from_node": 6, "to_node": 7, "to_port": "source" }
  ]
}
```
