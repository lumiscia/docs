---
title: Source
description: Nodes that create rasters from media, paint and text.
---

Source nodes create rasters from media, paint or text. They have no input ports.

- [Background](background) (`background`): generates a background raster texture.
- [Media In](media-in) (`media_in`): binds an external image or video frame as a GPU texture.
- [Text](text) (`text`): produces a text source.
