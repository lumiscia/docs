---
title: Media In
description: Binds an external image or video frame as a GPU texture.
---

import { NodeReference } from "@/src/components/mdx/node-reference";

`media_in` reads an image or video from the render request's media manifest. Set `source` to a manifest alias, and set `kind` to `video` for video files so the range, speed and loop params apply.

<NodeReference type="media_in" />

## Example

```json
{
  "id": 1,
  "type": "media_in",
  "params": {
    "source": "hero",
    "kind": "video",
    "loop_mode": "repeat"
  }
}
```
