---
title: Text
description: Produces a text source.
---

`text` lays out a string in a font and draws it to a raster. The `glyph_*` params are evaluated once per glyph and can read `glyph`, `word` and `line`, so you can stagger an animation across letters.

<NodeReference type="text" />

## Example

```json
{
  "id": 1,
  "type": "text",
  "params": {
    "content": "Hello",
    "font_size": 96,
    "position": [640, 360],
    "alignment_horizontal": "center",
    "glyph_opacity": "=progress(glyph * 2, glyph * 2 + 10)"
  }
}
```
