---
title: Path
description: Produces a rasterized vector path source.
---

`path` draws SVG-style path data to a raster, with an optional fill and stroke. Animate `trim_start` or `trim_end` to draw a stroke on over time.

<NodeReference type="path" />

## Example

```json
{
  "id": 1,
  "type": "path",
  "params": {
    "data": "M 0 0 C 80 -60 160 60 240 0",
    "position": [520, 360],
    "fill_enabled": false,
    "stroke_enabled": true,
    "stroke_width": 6,
    "trim_end": "=progress(0, 30)"
  }
}
```
