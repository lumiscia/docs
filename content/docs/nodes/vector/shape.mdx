`shape` draws a rectangle or an ellipse to a raster, with an optional fill and stroke. `width` and `height` take fractional pixels, so an animated or measured size doesn't snap to whole pixels. To draw a polygon, use a [`path`](path) with closed path data, such as `M 0 0 L 120 0 L 60 100 Z`.

<NodeReference type="shape" />

## Example

```json
{
  "id": 1,
  "type": "shape",
  "params": {
    "geometry_kind": "rectangle",
    "width": 320,
    "height": 120,
    "border_radius": 24,
    "position": [480, 300],
    "fill_paint": "#2c45c2"
  }
}
```

## Repeat

`repeat` draws up to 1024 copies of the node in one pass. Copy `i` adds `i` times `rotation_offset`, `scale_offset` and `opacity_offset` to the node's own rotation, scale and opacity, about its own anchor, and moves by `position_offset` per column. With `columns` set, copies wrap into rows that move by `row_offset`. Each copy's opacity is clamped to 0 to 1, and later copies draw over earlier ones.

| Field             | Default  | Description                                                                                                 |
| ----------------- | -------- | ----------------------------------------------------------------------------------------------------------- |
| `count`           | Required | Copies to draw, from 0 to 1024. 0 draws nothing and 1 draws the node alone.                                 |
| `columns`         | `0`      | Copies per row. 0 puts every copy in one row.                                                               |
| `position_offset` | `[0, 0]` | Pixels added for each column.                                                                               |
| `row_offset`      | `[0, 0]` | Pixels added for each row.                                                                                  |
| `rotation_offset` | `0`      | Clockwise degrees added for each copy.                                                                      |
| `scale_offset`    | `[0, 0]` | Scale added for each copy, per axis. A negative offset shrinks later copies through 0 into mirrored copies. |
| `opacity_offset`  | `0`      | Opacity added for each copy.                                                                                |

Each field takes a literal or an expression, evaluated once per frame, but the whole `repeat` can't be one expression. A 4 × 3 grid of dots:

```json
{
  "id": 1,
  "type": "shape",
  "params": {
    "geometry_kind": "ellipse",
    "width": 40,
    "height": 40,
    "position": [400, 240],
    "fill_paint": "#f5b301",
    "repeat": { "count": 12, "columns": 4, "position_offset": [80, 0], "row_offset": [0, 80] }
  }
}
```
