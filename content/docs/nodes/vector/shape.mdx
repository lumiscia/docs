---
title: Shape
description: Produces a vector shape layer for GPU rasterization.
---

`shape` draws a rectangle, ellipse or polygon to a raster, with an optional fill and stroke. `width` and `height` size rectangles and ellipses; for a polygon, set `geometry_kind` to `polygon` and list its vertices in `polygon_points`.

<NodeReference type="shape" />

## Example

```json
{
  "id": 1,
  "type": "shape",
  "params": {
    "geometry_kind": "rectangle",
    "width": 320,
    "height": 120,
    "border_radius": 24,
    "position": [480, 300],
    "fill_paint": "#2c45c2"
  }
}
```
