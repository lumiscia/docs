Lumen is the rendering engine behind Lumiscia. It lives in the public [lumiscia/lumen-oss](https://github.com/lumiscia/lumen-oss) repository under the Apache 2.0 license. Lumiscia is the hosted platform around it, with the API at `https://api.lumiscia.com/v1`, the dashboard at [lumiscia.com](https://lumiscia.com), media storage, billing, and the GPU render workers.

Lumen is in heavy beta. Expect breaking changes in crate APIs, schema shapes, node behavior, and package structure.

## How a hosted render runs

1. Your backend sends a composition and its media manifest to `POST https://api.lumiscia.com/v1/renders` with an API key.
2. The API validates the composition and the media it references, then queues the render. Each workspace has its own scheduler, which enforces your plan's concurrency limit and [queue priority](../pricing).
3. A GPU render worker picks up the render and runs it with `lumen-server`, the same crate you can [run yourself](self-hosting).
4. The worker uploads the MP4 artifact to Lumiscia's storage and reports the result and the measured render time.
5. The API marks the render `succeeded` or `failed`, bills the render time, sends render events to subscribers, and delivers your webhook.

Browser previews skip this pipeline. `@lumiscia/lumen-react` and `@lumiscia/lumen-svelte` run Lumen compiled to WebAssembly on the viewer's device, so previews are free and need no API key. Preview output can differ from cloud renders in edge cases while the bindings evolve.

## What is open source

| Open source in `lumen-oss`                                                  | Hosted only                                    |
| --------------------------------------------------------------------------- | ---------------------------------------------- |
| Rendering engine, GPU, FFmpeg, and text crates                              | The Lumiscia API and render scheduling         |
| `lumen-server`, with render service primitives and a local HTTP binary      | The GPU worker that wraps `lumen-server`       |
| Composition schema and node definitions                                     | Media upload, URL ingest, and media validation |
| TypeScript packages: SDK, composition builder, types, preview, and bindings | Dashboard, editor, accounts, API keys, billing |

`@lumiscia/lumen-sdk` is open source too. It mainly calls the hosted API, and it also works against a local `lumen-server`.

## Hosted or self-hosted

Lumiscia is the supported production path. It provides managed GPUs, media storage, artifact delivery, and the operations around them.

Self-hosting works but is hands-on. `lumen-server` renders compositions on your own GPU, and you supply the queueing, storage, auth, and deployment around it.
