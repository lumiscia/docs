title: Packages and crates
description: What each Lumen npm package and Rust crate does, and which ones to install.
---

Lumen publishes seven `@lumiscia/lumen-*` packages to npm and six crates to crates.io. All of them come from [lumiscia/lumen-oss](https://github.com/lumiscia/lumen-oss) and are released together under one version number.

## Which ones you need

- To render on Lumiscia from a backend, install `@lumiscia/lumen-sdk`. It re-exports the composition builder.
- To build compositions in the browser, install `@lumiscia/lumen-shared`.
- To preview compositions in the browser, install `@lumiscia/lumen-react` or `@lumiscia/lumen-svelte`, plus `@lumiscia/lumen-shared` and `@lumiscia/lumen-bindings`.
- To render on your own GPU, run `lumen-server`. See [Self-hosting](self-hosting).

Setup for each is in the [Node](../sdks/node), [Cloudflare](../sdks/cloudflare), [Browser](../sdks/browser), [React](../sdks/react), and [Svelte](../sdks/svelte) pages.

## npm packages

| Package                    | What it does                                                                                                                            |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `@lumiscia/lumen-sdk`      | API client for media uploads, URL ingest, renders, render events, and artifacts. Exports the `Lumen` class, plus a `/cloudflare` entry. |
| `@lumiscia/lumen-shared`   | Dependency-light composition builder (`Composition`, `AudioTrack`) and expression helpers. Safe to use in the browser.                  |
| `@lumiscia/lumen-types`    | Generated TypeScript types and node metadata for the composition schema, such as `LumenComposition`.                                    |
| `@lumiscia/lumen-preview`  | Browser preview runtime and media bridge. The React and Svelte packages build on it.                                                    |
| `@lumiscia/lumen-react`    | React preview components and hooks, such as `LumenCanvas` and `useLumenPreview`. Requires React 18 or later.                            |
| `@lumiscia/lumen-svelte`   | Svelte preview components and state helpers, such as `LumenCanvas` and `createLumenPreview`. Requires Svelte 5 or later.                |
| `@lumiscia/lumen-bindings` | Generated WebAssembly bindings with the compiled module included. Entry points are `/bundler` (the default), `/browser`, and `/node`.   |

## Rust crates

| Crate                 | What it does                                                                                      |
| --------------------- | ------------------------------------------------------------------------------------------------- |
| `lumen-server`        | Render service primitives for custom render platforms, plus the `lumen-server` local HTTP binary. |
| `lumen-engine`        | Core composition model, node system, media handling, and GPU render orchestration.                |
| `lumen-engine-gpu`    | Lower-level `wgpu` renderer resources, programs, passes, and Vulkan export helpers.               |
| `lumen-engine-ffmpeg` | FFmpeg bindings for decode, encode, muxing, and GPU frame interop.                                |
| `lumen-engine-text`   | Text layout and glyph data helpers.                                                               |
| `lumen-engine-macros` | Procedural macros for node metadata, used internally by `lumen-engine`. Not a stable public API.  |

Start with `lumen-server`. The other crates track renderer internals and change often.

The repository also has four crates that are not published:

| Crate              | What it does                                                                |
| ------------------ | --------------------------------------------------------------------------- |
| `lumen-local`      | Local render and debugging CLI.                                             |
| `lumen-bench`      | Benchmarks for composition rendering, JSON parsing, media decode, and text. |
| `lumen-generators` | Generates the JSON schema and node metadata from the Rust node definitions. |
| `lumen-wasm`       | Browser renderer bindings, compiled into `@lumiscia/lumen-bindings`.        |

The generated schema is [`definitions/composition.schema.json`](https://github.com/lumiscia/lumen-oss/blob/main/definitions/composition.schema.json).

All packages and crates are experimental. Pin exact versions and read the [release notes](https://github.com/lumiscia/lumen-oss/releases) before upgrading.
