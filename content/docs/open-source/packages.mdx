title: Packages and crates
description: What each Lumen npm package and Rust crate does, and which ones to install.
---

Lumen publishes eight `@lumiscia/lumen-*` packages to npm and seven crates to crates.io. All of them come from [lumiscia/lumen-oss](https://github.com/lumiscia/lumen-oss) and are released together under one version number.

## Which ones you need

- To render on Lumiscia from a backend, install `@lumiscia/lumen-sdk`. It re-exports the composition builder.
- To build compositions in the browser, install `@lumiscia/lumen-shared`.
- To preview compositions in the browser, install `@lumiscia/lumen-react` or `@lumiscia/lumen-svelte`, plus `@lumiscia/lumen-shared`. Without a framework, install `@lumiscia/lumen-preview` and `@lumiscia/lumen-bindings`.
- To check and render compositions on your own machine, install `@lumiscia/lumen-cli`. See [Lumen CLI](cli).
- To serve renders from your own GPU, run `lumen-server`. See [Self-hosting](self-hosting).

Setup for each is in the [Node](../sdks/node), [Cloudflare](../sdks/cloudflare), [Browser](../sdks/browser), [React](../sdks/react), and [Svelte](../sdks/svelte) pages.

## npm packages

| Package                    | What it does                                                                                                                                                                                                                |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@lumiscia/lumen-sdk`      | API client for media uploads, URL ingest, renders, render progress, cancellation, artifacts, and webhook verification. Exports the `Lumen` class and re-exports `@lumiscia/lumen-shared`.                                   |
| `@lumiscia/lumen-shared`   | Dependency-light composition builder (`Composition` and the `nodes` values), templates, and expression helpers. Safe to use in the browser.                                                                                 |
| `@lumiscia/lumen-types`    | Generated TypeScript types and node metadata for the composition schema, such as `LumenComposition`.                                                                                                                        |
| `@lumiscia/lumen-preview`  | Browser preview runtime: `createLumenPreview` and `mountPreview`. The React and Svelte packages build on it. `/advanced` exports types for custom hosts.                                                                    |
| `@lumiscia/lumen-react`    | React preview components and hooks, such as `Player` and `useLumenPreview`. Requires React 18 or later, and installs `@lumiscia/lumen-bindings` itself.                                                                     |
| `@lumiscia/lumen-svelte`   | Svelte preview components and state helpers, such as `Player` and `createLumenPreview`. Requires Svelte 5 or later, and installs `@lumiscia/lumen-bindings` itself.                                                         |
| `@lumiscia/lumen-bindings` | The engine compiled to WebAssembly, and the preview worker. `/urls` names the worker and wasm for `mountPreview`. `.` (also `/browser` and `/bundler`) and `/node` load the engine to check compositions, but don't render. |
| `@lumiscia/lumen-cli`      | The `lumen` command, which checks and renders compositions on a local GPU. Installs a prebuilt binary for Linux x64 and arm64 and macOS on Apple silicon.                                                                   |

## Rust crates

| Crate                 | What it does                                                                                     |
| --------------------- | ------------------------------------------------------------------------------------------------ |
| `lumen-server`        | Render library for custom render platforms, plus the `lumen-server` local HTTP binary.           |
| `lumen-engine`        | Core composition model, node system, media handling, and GPU render orchestration.               |
| `lumen-engine-gpu`    | Lower-level `wgpu` renderer resources, programs, passes, and Vulkan export helpers.              |
| `lumen-engine-ffmpeg` | FFmpeg bindings for decode, encode, muxing, and GPU frame interop.                               |
| `lumen-engine-text`   | Text layout and glyph data helpers.                                                              |
| `lumen-engine-3d`     | Scene maths, meshes, and glTF models for the 3D nodes.                                           |
| `lumen-engine-macros` | Procedural macros for node metadata, used internally by `lumen-engine`. Not a stable public API. |

Start with `lumen-server`. The other crates track renderer internals and change often.

The repository also has four crates that are not published:

| Crate              | What it does                                                                |
| ------------------ | --------------------------------------------------------------------------- |
| `lumen-cli`        | The `lumen` command, published to npm as `@lumiscia/lumen-cli`.             |
| `lumen-bench`      | Benchmarks for composition rendering, JSON parsing, media decode, and text. |
| `lumen-generators` | Generates the JSON schema and node metadata from the Rust node definitions. |
| `lumen-wasm`       | Browser renderer bindings, compiled into `@lumiscia/lumen-bindings`.        |

The generated schema is [`definitions/composition.schema.json`](https://github.com/lumiscia/lumen-oss/blob/main/definitions/composition.schema.json).

All packages and crates are experimental. Pin exact versions and read the [release notes](https://github.com/lumiscia/lumen-oss/releases) before upgrading.
