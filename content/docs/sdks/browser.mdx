title: Browser
description: Build and preview compositions in the browser, and render them through your backend.

Browser code builds and previews compositions. Your backend uploads media and creates renders, because every Lumiscia API call needs your API key.

<Callout type="error" title="Never ship an API key to the browser">
  An API key can spend your workspace balance and read its renders and media. Keep it on your
  server. The media upload URL also requires the key, so the browser can't upload to Lumiscia
  directly. Send files to your backend and call `uploadMedia` there.
</Callout>

| Task                                    | Package                                                                              | Runs in |
| --------------------------------------- | ------------------------------------------------------------------------------------ | ------- |
| Build composition JSON                  | `@lumiscia/lumen-shared`                                                             | Browser |
| Preview a composition                   | `@lumiscia/lumen-react` or `@lumiscia/lumen-svelte`, plus `@lumiscia/lumen-bindings` | Browser |
| Upload media, create and follow renders | `@lumiscia/lumen-sdk`                                                                | Server  |

## Build a composition

`@lumiscia/lumen-shared` only builds JSON. It makes no network calls and needs no key, so it is safe in client code. See the [Composition builder](../guides/composition-builder) guide for the full API.

```bash
npm install @lumiscia/lumen-shared
```

```ts
import { Composition } from "@lumiscia/lumen-shared";

const composition = new Composition({
  renderSettings: { width: 1280, height: 720 },
  timeline: { fps: 30, durationSeconds: 3 },
});

const background = composition.addNode({
  type: "background",
  params: { paint: [18, 24, 32, 255] },
});
const hero = composition.addNode({
  type: "media_in",
  params: { kind: "image", source: "hero" },
});
const merge = composition.addNode({ type: "merge", params: { blend_mode: "normal" } });
const output = composition.addNode({ type: "media_output" });

composition.connect(background, merge, { toPort: "base" });
composition.connect(hero, merge, { toPort: "overlay" });
composition.connect(merge, output, { toPort: "source" });
```

The `media_in` node reads the alias `hero`. In preview, you register a local file under that alias. At render time, the backend maps the same alias to uploaded media.

## Preview

The [React](react) and [Svelte](svelte) packages play the composition in a worker, with the Lumen engine compiled to WebAssembly. Pass local files to the player's `media` prop, keyed by alias, for example `{ hero: file }`.

A source can be a `File` or `Blob`, a URL string or `URL`, or raw bytes, so you can preview a file before it is uploaded.

The preview needs a browser with WebGPU and `OffscreenCanvas`. WebGPU also needs HTTPS or localhost.

### Bindings

`@lumiscia/lumen-bindings` holds the WebAssembly build and the preview worker. Pass `createLumenBindings()` to the player as `bindings`, imported from the entry point that fits your setup:

| Entry point                        | Use                                                                                                                          |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `@lumiscia/lumen-bindings/bundler` | Vite. Needs no plugins or config.                                                                                            |
| `@lumiscia/lumen-bindings`         | Browsers without a bundler. To serve the wasm or the worker from your own URLs, pass `previewWasmUrl` or `previewWorkerUrl`. |
| `@lumiscia/lumen-bindings/node`    | Node.js. Parses compositions but can't render, because rendering needs a browser's WebGPU.                                   |

## Render through your backend

Send the composition JSON and the file to your backend:

```ts title="client.ts"
const form = new FormData();
form.append("composition", JSON.stringify(composition.toJSON()));
form.append("hero", file);

const response = await fetch("/api/renders", { method: "POST", body: form });
const { id } = await response.json();
```

On the server, upload the file and create the render. This example uses Node.js. On [Cloudflare Workers](cloudflare), import from the same package and read the key from the Worker's environment.

```ts title="server.ts"
import { Lumen } from "@lumiscia/lumen-sdk";

const lumen = new Lumen({
  apiKey: process.env.LUMISCIA_API_KEY!,
  baseUrl: "https://api.lumiscia.com/v1",
});

export async function createRender(form: FormData) {
  const composition = JSON.parse(String(form.get("composition")));
  const file = form.get("hero") as File;

  const hero = await lumen.uploadMedia({ body: file });

  return lumen.render(composition, { media: { hero } });
}
```

Before you submit a composition that came from the browser, check it against your own rules (allowed node types, size, duration), since the render is billed to your workspace. The [Preview to render](../guides/preview-to-render) guide covers the full workflow.
