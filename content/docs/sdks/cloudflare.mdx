Use `@lumiscia/lumen-sdk/cloudflare` in Workers. This entrypoint uses Worker-native `fetch` WebSocket upgrades for render subscriptions.

Build graph JSON with the shared [Composition Builder](../guides/composition-builder), then use the Cloudflare SDK entrypoint for Worker-native API calls and subscriptions.

## Install

```bash
npm install @lumiscia/lumen-sdk
```

## Create a Worker Client

```ts
import { Composition, Lumen, mediaReference } from "@lumiscia/lumen-sdk/cloudflare";

export interface Env {
  LUMEN_API_KEY: string;
}

export default {
  async fetch(_request: Request, env: Env): Promise<Response> {
    const lumen = new Lumen({
      apiKey: env.LUMEN_API_KEY,
      baseUrl: "https://lumen.lumiscia.com",
    });

    const plate = await lumen.createUrlMedia({
      fileName: "plate.png",
      url: "https://example.com/plate.png",
    });

    const composition = new Composition({
      renderSettings: {
        width: 1280,
        height: 720,
      },
      timeline: {
        fps: 30,
        durationSeconds: 4,
      },
    });

    const background = composition.addImage("plate", {
      rangeStart: 0,
      rangeEnd: 120,
      loop: true,
    });

    composition.addOutput(background);

    const result = await lumen.render(composition, {
      media: {
        plate: mediaReference(plate),
      },
    });

    return Response.json(result, { status: result.error ? 500 : 202 });
  },
};
```

## Subscribe in Workers

Cloudflare Workers can create WebSocket connections by calling `fetch()` with an `Upgrade: websocket` request. The Cloudflare SDK entrypoint wires that behavior for `subscribeToRender`.

```ts
const subscription = await lumen.subscribeToRender(renderId, {
  onEvent: (event) => {
    console.log(event);
  },
  onError: (error) => {
    console.error(error);
  },
});
```

## Notes

- Store `LUMEN_API_KEY` as a Worker secret.
- Pass the Lumen origin as `baseUrl`; the SDK appends `/api/v1`.
- Use the default `@lumiscia/lumen-sdk` import in Node.js, and the `/cloudflare` export in Workers.
