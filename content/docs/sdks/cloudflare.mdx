title: Cloudflare Workers
description: Use the Lumiscia SDK from Cloudflare Workers.
---

In a Worker, import from `@lumiscia/lumen-sdk`, the same package and import as on [Node.js](node). The SDK uses only web APIs (`fetch`, Web Crypto, and a `fetch()` WebSocket upgrade), so it needs no Node.js compatibility flag.

```bash
npm install @lumiscia/lumen-sdk
```

Store the API key as a Worker secret:

```bash
npx wrangler secret put LUMISCIA_API_KEY
```

## Create a render

This Worker ingests an image from a URL, renders it for 3 seconds, and asks Lumiscia to call a webhook when the render finishes.

```ts title="src/index.ts"
import { Composition, Lumen } from "@lumiscia/lumen-sdk";

interface Env {
  LUMISCIA_API_KEY: string;
}

export default {
  async fetch(_request: Request, env: Env): Promise<Response> {
    const lumen = new Lumen({
      apiKey: env.LUMISCIA_API_KEY,
      baseUrl: "https://api.lumiscia.com/v1",
    });

    const plate = await lumen.createUrlMedia({
      fileName: "plate.jpg",
      url: "https://images.unsplash.com/photo-1546069901-ba9599a7e63c?w=1280&h=720&fit=crop",
    });

    const composition = new Composition({
      renderSettings: { width: 1280, height: 720 },
      timeline: { fps: 30, durationSeconds: 3 },
    });
    const image = composition.addNode({
      type: "media_in",
      params: { kind: "image", source: "plate" },
    });
    composition.addNode({ type: "media_output", inputs: { source: image } });

    const { id } = await lumen.render(composition, {
      media: { plate },
      webhookUrl: "https://example.com/webhooks/lumiscia",
    });

    return Response.json({ id }, { status: 202 });
  },
};
```

`createUrlMedia` and `render` throw a `LumenError` if they fail. Catch it if you want to return your own error response.

## Follow a render

`waitForRender` works the same as on [Node.js](node#wait-for-a-render). In a Worker it opens the render's WebSocket with a `fetch()` upgrade, which closes when the invocation that opened it ends. For renders that outlast a request, set `webhookUrl` and handle the result in a [webhook](../guides/webhooks). `verifyWebhook` uses Web Crypto, so it checks signatures in a Worker too.

The SDK uses the `fetch` you pass in `LumenOptions`, or `globalThis.fetch`, for both API calls and the WebSocket upgrade.
