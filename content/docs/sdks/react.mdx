`@lumiscia/lumen-react` plays a composition in a `<canvas>` using the Lumen engine compiled to WebAssembly. It needs React 18 or later. Preview runs entirely in the browser and needs no API key. To produce a video file, send the same composition to your backend and [render it there](browser#render-through-your-backend).

```bash
npm install @lumiscia/lumen-react @lumiscia/lumen-shared @lumiscia/lumen-bindings
npm install -D vite-plugin-wasm vite-plugin-top-level-await
```

`@lumiscia/lumen-bindings` holds the WebAssembly build. Its `/bundler` entry point loads the preview worker with Vite's `?worker&url` import, so these docs assume Vite.

## Configure Vite

```ts title="vite.config.ts"
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";
import topLevelAwait from "vite-plugin-top-level-await";
import wasm from "vite-plugin-wasm";

export default defineConfig({
  build: { target: "esnext" },
  plugins: [wasm(), topLevelAwait(), react()],
});
```

## Render a preview

Create the preview controller and bindings once, outside your components. `LumenCanvas` starts a new engine session whenever `preview` or `bindings` changes, and updates the running session when other props change.

```tsx title="Preview.tsx"
import { Composition } from "@lumiscia/lumen-shared";
import { LumenCanvas, createLumenPreview, useLumenPreview } from "@lumiscia/lumen-react";
import { createLumenBindings } from "@lumiscia/lumen-bindings/bundler";

const composition = new Composition({
  renderSettings: { width: 1280, height: 720 },
  timeline: { fps: 30, durationSeconds: 4 },
});

const background = composition.addNode({
  type: "background",
  params: { paint: [25, 28, 36, 255] },
});
const title = composition.addNode({
  type: "text",
  params: {
    content: "Hello from Lumen",
    font_size: 76,
    font_weight: 700,
    color: [255, 255, 255, 255],
  },
});
const merge = composition.addNode({ type: "merge", params: { blend_mode: "normal" } });
const output = composition.addNode({ type: "media_output" });

composition.connect(background, merge, { toPort: "base" });
composition.connect(title, merge, { toPort: "overlay" });
composition.connect(merge, output, { toPort: "source" });

const preview = createLumenPreview();
const bindings = createLumenBindings();
const compositionJson = JSON.stringify(composition.toJSON());

export function Preview() {
  const state = useLumenPreview(preview);

  return (
    <main>
      <LumenCanvas preview={preview} bindings={bindings} compositionJson={compositionJson} />
      <button
        type="button"
        disabled={!state.isLoaded}
        onClick={() => (state.isPlaying ? preview.pause() : preview.play())}
      >
        {!state.isLoaded ? "Loading" : state.isPlaying ? "Pause" : "Play"}
      </button>
      <span>
        Frame {state.frame} / {state.totalFrames}
      </span>
      {state.error ? <pre>{state.error}</pre> : null}
    </main>
  );
}
```

`useLumenPreview(preview)` returns the current state: `frame`, `totalFrames`, `width`, `height`, `isLoaded`, `isPlaying`, and `error` (a string or `null`). Control playback with `preview.play()`, `preview.pause()`, and `preview.seek(frame)`.

## Add media

Register images and videos with `mediaSources`. Each `id` must match the `source` param of a `media_in` node. Keep the array stable (module scope, `useMemo`, or state), because a new array makes the canvas sync its media again.

```tsx
import type { MediaRegistration } from "@lumiscia/lumen-react";

const mediaSources: MediaRegistration[] = [
  { kind: "image", id: "hero", source: "/hero.png" },
  { kind: "video", id: "intro", source: "/intro.mp4" },
];

<LumenCanvas
  preview={preview}
  bindings={bindings}
  compositionJson={compositionJson}
  mediaSources={mediaSources}
/>;
```

`source` accepts a URL string or `URL`, a `Request`, a `File` or `Blob`, or raw bytes. Audio works the same way through `audioSources` (`{ kind: "audio", id, source }`), where `id` matches an audio clip's `sourceId`. See [Media sources](../guides/media-sources).

## `LumenCanvas` props

| Prop              | Type                                                         | Default | Description                                                                            |
| ----------------- | ------------------------------------------------------------ | ------- | -------------------------------------------------------------------------------------- |
| `preview`         | `LumenPreviewContext`                                        |         | Controller from `createLumenPreview()`. Required.                                      |
| `bindings`        | `LumenPreviewBindingSource`                                  |         | WebAssembly bindings from `createLumenBindings()`. Required.                           |
| `compositionJson` | `string \| null`                                             | `null`  | Composition as a JSON string.                                                          |
| `mediaSources`    | `MediaRegistration[]`                                        | `[]`    | Images and videos, keyed by `media_in` source alias.                                   |
| `audioSources`    | `AudioSourceRegistration[]`                                  | `[]`    | Audio files, keyed by audio clip `sourceId`.                                           |
| `lookaheadCount`  | `number`                                                     | `8`     | Frames whose media the preview loads ahead of the playhead.                            |
| `logLevel`        | `"off" \| "error" \| "warn" \| "info" \| "debug" \| "trace"` | `"off"` | Engine log level.                                                                      |
| `onStats`         | `(stats) => void`                                            |         | Receives `frame`, `timelineFps`, `targetFrameDurationMs`, `renderMs`, and `actualFps`. |
| `className`       | `string`                                                     |         | Class for the `<canvas>`.                                                              |
| `style`           | `CSSProperties`                                              |         | Inline style for the `<canvas>`.                                                       |

The canvas's `width` and `height` attributes follow the composition's render size. Size it on the page with CSS.
