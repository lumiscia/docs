title: Svelte
description: Preview compositions in Svelte with the Lumen WebAssembly renderer.
---

Use `@lumiscia/lumen-svelte` with `@lumiscia/lumen-shared` and `@lumiscia/lumen-bindings`.

Build the composition itself with the [Composition Builder](../guides/composition-builder), then pass serialized JSON into the Svelte preview canvas.

## Install

```bash
npm install @lumiscia/lumen-svelte @lumiscia/lumen-shared @lumiscia/lumen-bindings
```

Vite projects should enable WASM and top-level await support:

```bash
npm install -D vite-plugin-wasm vite-plugin-top-level-await
```

## Vite Configuration

```ts
import { svelte } from "@sveltejs/vite-plugin-svelte";
import topLevelAwait from "vite-plugin-top-level-await";
import wasm from "vite-plugin-wasm";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [svelte(), wasm(), topLevelAwait()],
});
```

## Preview Canvas

```svelte
<script lang="ts">
  import { Composition } from "@lumiscia/lumen-shared";
  import { LumenCanvas, createLumenPreview } from "@lumiscia/lumen-svelte";
  import { createLumenBindings } from "@lumiscia/lumen-bindings/bundler";

  const composition = new Composition({
    renderSettings: { width: 1280, height: 720 },
    timeline: { fps: 30, durationSeconds: 4 },
  });
  const background = composition.addSolidColor({
    width: 1280,
    height: 720,
    color: [25, 28, 36, 255],
  });
  composition.addOutput(background);

  const preview = createLumenPreview();
  const lumenBindings = createLumenBindings();
  const compositionJson = JSON.stringify(composition.toJSON());
</script>

<main>
  <LumenCanvas {preview} bindings={lumenBindings} {compositionJson} />
  <button
    type="button"
    disabled={!preview.isLoaded}
    onclick={() => (preview.isPlaying ? preview.pause() : preview.play())}
  >
    {!preview.isLoaded ? "Loading" : preview.isPlaying ? "Pause" : "Play"}
  </button>
  <span>Frame {preview.frame} / {preview.totalFrames}</span>
  {#if preview.error}
    <pre>{preview.error}</pre>
  {/if}
</main>
```

## Bindings

Use `@lumiscia/lumen-bindings/bundler` in Vite apps. The `bindings` prop keeps the Svelte package independent from one specific wasm-bindgen target.
