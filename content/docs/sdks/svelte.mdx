title: Svelte

`@lumiscia/lumen-svelte` plays a composition in a `<canvas>` using the Lumen engine compiled to WebAssembly. It needs Svelte 5 and a browser with WebGPU. Preview runs entirely in the browser and needs no API key. To produce a video file, send the same composition to your backend and [render it there](browser#render-through-your-backend).

```bash
npm install @lumiscia/lumen-svelte @lumiscia/lumen-shared
```

The preview renders in a worker that loads the WebAssembly engine. Both come from `@lumiscia/lumen-bindings`, which `@lumiscia/lumen-svelte` depends on and finds by itself with Vite or plain ESM. To serve them from elsewhere, see [Runtime files](browser#runtime-files).

## Render a preview

`createLumenPreview()` returns a controller whose `state` field is a reactive snapshot, so read `preview.state.isLoaded`, `preview.state.frame`, and the rest directly in markup. `Player` starts a new engine session whenever `preview` or a runtime URL changes, and updates the running session when other props change. It reloads only when the composition, media or fonts change.

```svelte title="Preview.svelte"
<script lang="ts">
  import { Composition, nodes as n } from "@lumiscia/lumen-shared";
  import { Player, createLumenPreview } from "@lumiscia/lumen-svelte";

  const composition = new Composition({
    renderSettings: { width: 1280, height: 720 },
    timeline: { fps: 30, durationSeconds: 4 },
  }).addOutput(
    n.merge({
      base: n.background({ paint: [25, 28, 36, 255] }),
      overlay: n.text({
        content: "Hello from Lumen",
        font_size: 76,
        font_weight: 700,
        color: [255, 255, 255, 255],
        position: [0, 320],
        max_width: 1280,
        alignment_horizontal: "center",
      }),
    }),
  );

  const preview = createLumenPreview();
</script>

<main>
  <Player {preview} {composition} loop />
  <button
    type="button"
    disabled={!preview.state.isLoaded}
    onclick={() => (preview.state.isPlaying ? preview.pause() : preview.play())}
  >
    {!preview.state.isLoaded ? "Loading" : preview.state.isPlaying ? "Pause" : "Play"}
  </button>
  <span>Frame {preview.state.frame} / {preview.state.totalFrames}</span>
  {#if preview.state.error}
    <pre>{preview.state.error}</pre>
  {/if}
</main>
```

`preview.state` holds `frame`, `totalFrames`, `width`, `height`, `isLoaded`, `isPlaying`, `error` (a message or `null`), `errorCode` (see [Errors](#errors)), and `media`, which counts the sources the composition needs as `{ pending, ready, failed }`.

Control playback with `preview.play()`, `preview.pause()`, and `preview.seek(frame)`. `play()` before the composition has loaded is ignored. `seek` returns a promise that resolves to `true` once that frame, or a later seek's frame, is on screen, and to `false` if a load or failure got in first.

`preview.whenReady()` resolves once a frame of the current composition is drawn and nothing it needs is still loading. It never rejects. It resolves with `null`, or with the error that stopped the composition loading, so check the value.

## Playback options

`Player` takes these props and applies them live, without reloading or restarting playback:

| Prop           | Default | Effect                                                                                                                                          |
| -------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `loop`         | `false` | Plays on from the start of the range at its end, with no gap, audio included. Without it, playback stops on the last frame and calls `onEnded`. |
| `rate`         | `1`     | Playback speed from `0.25` to `4`. Audio follows it, with its pitch.                                                                            |
| `volume`       | `1`     | Audio level from `0` to `1`.                                                                                                                    |
| `muted`        | `false` | Silences the audio without changing `volume`.                                                                                                   |
| `range`        | `null`  | `{ in, out }` plays only frames `in` to `out - 1`. Seeks land inside it. `null` plays the whole composition.                                    |
| `onEnded`      |         | Called once when playback reaches the end of the range without `loop`.                                                                          |
| `onTimeUpdate` |         | Called with `{ frame, timeMs }` at most once per frame shown. It doesn't touch `preview.state`.                                                 |

```svelte
<Player
  {preview}
  {composition}
  range={{ in: 30, out: 90 }}
  rate={1.5}
  volume={0.8}
  onEnded={() => console.log("ended")}
/>
```

A value it can't use, such as a `rate` of 8, is reported as an `invalid_option` error, and the whole update is rejected: the previous props stay in effect.

## Add media

Pass media in `media`, a map from each source name the composition uses to a file. A name is what a `media_in` `source`, an audio clip's `source_id`, a `model_3d` `source`, a `render_3d` `environment_map` or a `color_grade` `lut_source` holds, including an `asset:<id>`.

```svelte
<script lang="ts">
  let { file }: { file: File } = $props();
</script>

<Player {preview} {composition} media={{ hero: file, music: "/music.mp3", fox: "/models/fox.glb" }} />
```

A source can be a URL string or `URL`, a `File` or `Blob`, or raw bytes. Only the entries the composition names are fetched, and each is released when the composition stops naming it. The preview takes each source's kind from the node that reads it. When an expression computes a source, give the entry a `kind` unless its blob's type says it: `{ kind: "video", source }`. The kinds are `image`, `video`, `audio`, `model`, `environment` and `lut`.

A source is found by its exact name, and the preview follows `lumen-server`'s rules: a source written as a URL (`https://...`), or with a `..` part, is `media.not_found` even when `media` has an entry under it. Name the source, such as `intro.mp4`, and put the URL in `media` under that name. See [Media sources](../guides/media-sources).

While anything the composition needs is loading, the preview holds its last frame and pauses playback, audio included.

## Add fonts

Register fonts in `fonts`, a map from font family to source. A text node whose `font_family` names a registered family uses it. Other text falls back to Roboto, the font Lumen bundles.

```svelte
<Player {preview} {composition} fonts={{ Inter: "/fonts/Inter-Bold.ttf" }} />
```

## `Player` props

| Prop             | Type                                                         | Default | Description                                                                                  |
| ---------------- | ------------------------------------------------------------ | ------- | -------------------------------------------------------------------------------------------- |
| `preview`        | `LumenPreviewContext`                                        |         | Controller from `createLumenPreview()`. Required.                                            |
| `composition`    | `LumenPreviewComposition \| null`                            |         | Composition JSON as an object, or anything with `toJSON()`, such as a `Composition`.         |
| `media`          | `LumenPreviewMedia`                                          | `{}`    | Media, keyed by the source name the composition uses.                                        |
| `fonts`          | `LumenPreviewFonts`                                          | `{}`    | Fonts, keyed by font family.                                                                 |
| `loop`           | `boolean`                                                    | `false` | See [Playback options](#playback-options).                                                   |
| `rate`           | `number`                                                     | `1`     | See [Playback options](#playback-options).                                                   |
| `volume`         | `number`                                                     | `1`     | See [Playback options](#playback-options).                                                   |
| `muted`          | `boolean`                                                    | `false` | See [Playback options](#playback-options).                                                   |
| `range`          | `{ in: number; out: number } \| null`                        | `null`  | See [Playback options](#playback-options).                                                   |
| `onEnded`        | `() => void`                                                 |         | See [Playback options](#playback-options).                                                   |
| `onTimeUpdate`   | `({ frame, timeMs }) => void`                                |         | See [Playback options](#playback-options).                                                   |
| `onError`        | `(error: LumenPreviewError) => void`                         |         | Called with each failure the state's `error` shows. See [Errors](#errors).                   |
| `onStats`        | `(stats) => void`                                            |         | Receives `frame`, `timelineFps`, `targetFrameDurationMs`, `renderMs`, and `actualFps`.       |
| `lookaheadCount` | `number`                                                     | `8`     | Frames past the playhead whose video the preview decodes ahead.                              |
| `logLevel`       | `"off" \| "error" \| "warn" \| "info" \| "debug" \| "trace"` | `"off"` | Engine log level.                                                                            |
| `runtimeUrl`     | `string \| URL`                                              |         | A directory serving the preview's runtime files. See [Runtime files](browser#runtime-files). |
| `wasmUrl`        | `string \| URL`                                              |         | Where the engine's wasm is served. Defaults to the copy in `@lumiscia/lumen-bindings`.       |
| `workerUrl`      | `string \| URL`                                              |         | Where the preview worker is served. Defaults to the copy in `@lumiscia/lumen-bindings`.      |
| `class`          | `string`                                                     |         | Class for the player's `<div>`.                                                              |
| `style`          | `string`                                                     |         | Inline style for the player's `<div>`.                                                       |

`Player` renders a `<div>` with the canvas inside. The canvas renders at the composition's size, fills the `<div>` and keeps its aspect ratio, so size the `<div>` with CSS.

## Errors

When something fails, `preview.state.error` holds the message and `preview.state.errorCode` says what failed. `onError` receives the full `LumenPreviewError`, with its `code`, `message`, `diagnostics` and `media`.

| `errorCode`          | Meaning                                                                                                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `webgpu_unavailable` | The browser or page has no WebGPU or `OffscreenCanvas`. WebGPU also needs HTTPS or localhost.                                                                                 |
| `worker_failed`      | The worker or its wasm couldn't start, or the worker crashed. Check that both are served and that the page's CSP allows them (`worker-src`, `script-src 'wasm-unsafe-eval'`). |
| `load_failed`        | The composition, or a media source or font it needs, failed to load. The preview tries again when an input changes.                                                           |
| `render_failed`      | A frame failed to render. Playback pauses.                                                                                                                                    |
| `audio_failed`       | An audio source couldn't be decoded. The video keeps playing.                                                                                                                 |
| `invalid_option`     | A playback prop had a value the preview can't use. The previous props stay in effect.                                                                                         |

When the engine rejects the composition, `diagnostics` list what is wrong and where, as [`lumen check`](../open-source/cli#lumen-check) does. A `render_failed` error has one diagnostic with the engine's code, such as `render.gpu` for a GPU fault or `render.limit` for a limit the composition exceeds.

When a media source can't be used, `media` says which `source`, where the composition uses it, and why, with one of the codes `media.not_found`, `media.wrong_kind`, `media.unsupported`, `media.too_large` or `media.decode`. It is `null` for other failures.
