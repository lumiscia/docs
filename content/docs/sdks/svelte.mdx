`@lumiscia/lumen-svelte` plays a composition in a `<canvas>` using the Lumen engine compiled to WebAssembly. It needs Svelte 5. Preview runs entirely in the browser and needs no API key. To produce a video file, send the same composition to your backend and [render it there](browser#render-through-your-backend).

```bash
npm install @lumiscia/lumen-svelte @lumiscia/lumen-shared @lumiscia/lumen-bindings
```

`@lumiscia/lumen-bindings` holds the WebAssembly build and the worker the preview renders in. Its `/bundler` entry point works in Vite with no plugins or config. For other setups, see [Bindings](browser#bindings).

## Render a preview

`createLumenPreview()` returns a controller whose `state` field is a reactive snapshot, so read `preview.state.isLoaded`, `preview.state.frame`, and the rest directly in markup. `Player` starts a new engine session whenever `preview` or `bindings` changes, and updates the running session when other props change. It reloads only when the composition, media or fonts change.

```svelte title="Preview.svelte"
<script lang="ts">
  import { Composition } from "@lumiscia/lumen-shared";
  import { Player, createLumenPreview } from "@lumiscia/lumen-svelte";
  import { createLumenBindings } from "@lumiscia/lumen-bindings/bundler";

  const composition = new Composition({
    renderSettings: { width: 1280, height: 720 },
    timeline: { fps: 30, durationSeconds: 4 },
  });

  const background = composition.addNode({
    type: "background",
    params: { paint: [25, 28, 36, 255] },
  });
  const title = composition.addNode({
    type: "text",
    params: {
      content: "Hello from Lumen",
      font_size: 76,
      font_weight: 700,
      color: [255, 255, 255, 255],
    },
  });
  const merge = composition.addNode({ type: "merge", params: { blend_mode: "normal" } });
  const output = composition.addNode({ type: "media_output" });

  composition.connect(background, merge, { toPort: "base" });
  composition.connect(title, merge, { toPort: "overlay" });
  composition.connect(merge, output, { toPort: "source" });

  const preview = createLumenPreview();
  const bindings = createLumenBindings();
</script>

<main>
  <Player {preview} {bindings} {composition} />
  <button
    type="button"
    disabled={!preview.state.isLoaded}
    onclick={() => (preview.state.isPlaying ? preview.pause() : preview.play())}
  >
    {!preview.state.isLoaded ? "Loading" : preview.state.isPlaying ? "Pause" : "Play"}
  </button>
  <span>Frame {preview.state.frame} / {preview.state.totalFrames}</span>
  {#if preview.state.error}
    <pre>{preview.state.error}</pre>
  {/if}
</main>
```

`preview.state` holds `frame`, `totalFrames`, `width`, `height`, `isLoaded`, `isPlaying`, `error` (a message or `null`), and `errorCode` (see [Errors](#errors)). Control playback with `preview.play()`, `preview.pause()`, and `preview.seek(frame)`. `seek` returns a promise that resolves to `true` once that frame, or a later seek's frame, is on screen, and to `false` if a load or failure got in first.

## Add media

Pass images, videos and audio in `media`, a map from alias to source. Each alias matches the `source` param of a `media_in` node, or the `source` of an audio clip (`source_id` in composition JSON).

```svelte
<script lang="ts">
  let { file }: { file: File } = $props();
</script>

<Player {preview} {bindings} {composition} media={{ hero: file, music: "/music.mp3" }} />
```

A source can be a URL string or `URL`, a `File` or `Blob`, or raw bytes. The preview takes each source's kind from the composition or from the blob's type. When neither says, as for a `media_in` whose `source` is an expression, pass `{ kind: "video", source }`. See [Media sources](../guides/media-sources).

## Add fonts

Register fonts in `fonts`, a map from font family to source. A text node whose `font_family` names a registered family uses it. Other text falls back to Roboto, the font Lumen bundles.

```svelte
<Player {preview} {bindings} {composition} fonts={{ Inter: "/fonts/Inter-Bold.ttf" }} />
```

## `Player` props

| Prop             | Type                                                         | Default | Description                                                                            |
| ---------------- | ------------------------------------------------------------ | ------- | -------------------------------------------------------------------------------------- |
| `preview`        | `LumenPreviewContext`                                        |         | Controller from `createLumenPreview()`. Required.                                      |
| `bindings`       | `LumenWorkerBindings`                                        |         | WebAssembly bindings from `createLumenBindings()`. Required.                           |
| `composition`    | `LumenPreviewComposition \| null`                            |         | Composition JSON as an object, or anything with `toJSON()`, such as a `Composition`.   |
| `media`          | `LumenPreviewMedia`                                          | `{}`    | Images, videos and audio, keyed by alias.                                              |
| `fonts`          | `LumenPreviewFonts`                                          | `{}`    | Fonts, keyed by font family.                                                           |
| `lookaheadCount` | `number`                                                     | `8`     | Frames whose media the preview loads ahead of the playhead.                            |
| `logLevel`       | `"off" \| "error" \| "warn" \| "info" \| "debug" \| "trace"` | `"off"` | Engine log level.                                                                      |
| `onStats`        | `(stats) => void`                                            |         | Receives `frame`, `timelineFps`, `targetFrameDurationMs`, `renderMs`, and `actualFps`. |
| `class`          | `string`                                                     |         | Class for the player's `<div>`.                                                        |
| `style`          | `string`                                                     |         | Inline style for the player's `<div>`.                                                 |

`Player` renders a `<div>` with the canvas inside. The canvas renders at the composition's size, fills the `<div>` and keeps its aspect ratio, so size the `<div>` with CSS.

## Errors

When something fails, `preview.state.error` holds the message and `preview.state.errorCode` says what failed. The full error is also logged to the console. A media failure's message names its alias.

| `errorCode`          | Meaning                                                                                                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `webgpu_unavailable` | The browser or page has no WebGPU or `OffscreenCanvas`. WebGPU also needs HTTPS or localhost.                                                                                 |
| `worker_failed`      | The worker or its wasm couldn't start, or the worker crashed. Check that both are served and that the page's CSP allows them (`worker-src`, `script-src 'wasm-unsafe-eval'`). |
| `load_failed`        | The composition, or a media source or font it needs, failed to load. The preview tries again when an input changes.                                                           |
| `render_failed`      | A frame failed to render. Playback pauses.                                                                                                                                    |
| `audio_failed`       | An audio source couldn't be decoded. The video keeps playing.                                                                                                                 |
